# Device validation — 22 October 2026

## Existing emulator

The GitHub repository was empty. The app was implemented from scratch in the linked checkout.

Tested on the owner's existing `Pixel_4_API_30` AVD, serial `emulator-5554`, Android 11 / API 30, 1080 × 2280, density 440. Existing AVDs also included Pixel 3a/API 30 and Nexus 6/API 25. No Pixel 9 AVD was found in this installation. No AVD was created, deleted, wiped, or replaced.

The existing AVD needed runtime overrides because the global SDK environment pointed to a different SDK and the original Pixel skin files were absent. It was launched with its original SDK/image location, a numeric screen skin, software rendering, and the current ADB executable. Its local authorized ADB key was reused; key contents are not stored in this repository.

```powershell
$env:ANDROID_AVD_HOME = 'C:\Android\.android\avd'
$env:ANDROID_SDK_ROOT = 'C:\Android\sdk'
$env:ANDROID_HOME = 'C:\Android\sdk'
# The app build uses the current SDK at A:\AI\runtimes\android-sdk.
& 'C:\Android\sdk\emulator\emulator.exe' -avd Pixel_4_API_30 `
  -no-snapshot-save -no-boot-anim -skin 1080x2280 -gpu swiftshader `
  -adb-path 'A:\AI\runtimes\android-sdk\platform-tools\adb.exe'
```

These are machine-specific paths, not requirements for other developers.

## Reproduce the final installed state

```powershell
$adb = 'A:\AI\runtimes\android-sdk\platform-tools\adb.exe'
& $adb -s emulator-5554 install -r app\build\outputs\apk\debug\app-debug.apk
& $adb -s emulator-5554 install -r app\build\outputs\apk\androidTest\debug\app-debug-androidTest.apk
& $adb -s emulator-5554 shell am instrument -w `
  com.henry.chord.test/androidx.test.runner.AndroidJUnitRunner
& $adb -s emulator-5554 shell am start -n com.henry.chord/.MainActivity
```

The APK is at `app/build/outputs/apk/debug/app-debug.apk`. It is debug signed. Gradle's connected-test cleanup removes test installations, so the final installation uses direct ADB instrumentation and remains available.
